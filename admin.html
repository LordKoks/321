🚀 Запуск всего проекта

Команды для запуска
🐳 Полный стек (рекомендуется)
Docker Compose
Шаг 1 — перейти в папку и создать .env
cd social-api cp .env.example .env # Отредактируйте .env: заполните SECRET_KEY и ключи API
Шаг 2 — собрать и запустить
docker compose up --build -d
Шаг 3 — проверить логи
docker compose logs -f api
Открыть :80 (Nginx) Swagger Docs :8000
🌐 Landing Page (index.html)
Static HTML
Открыть в браузере (файл)
open index.html # macOS # или просто дважды кликните на index.html
Локальный dev-сервер (Python)
python3 -m http.server 3000 # Откройте: http://localhost:3000/index.html
Открыть Landing :3000 Dev Server
⚡ API сервер (без Docker)
Local Python
Установить зависимости
cd social-api pip install -e .
Запустить FastAPI + Uvicorn
uvicorn app.main:app --reload --port 8000
/health check Swagger
⚙️ Celery Worker + Beat
Background Tasks
Запустить воркер
cd social-api celery -A app.tasks.celery_app worker \ --loglevel=info --concurrency=4
Запустить scheduler (beat)
cd social-api celery -A app.tasks.celery_app beat --loglevel=info
Мониторинг задач (Flower)
celery -A app.tasks.celery_app flower --port=5555
Flower UI :5555
🗄️ База данных PostgreSQL
Postgres 16
Запустить только БД через Docker
cd social-api docker compose up -d db redis
Применить миграции Alembic
cd social-api alembic upgrade head
Подключиться к БД (psql)
docker compose exec db psql -U user -d social_api
🧪 Тесты
pytest
Все тесты
cd social-api && pytest -v
Конкретный тест-файл
pytest tests/test_auth.py -v pytest tests/test_accounts.py -v pytest tests/test_posts.py -v
С покрытием кода
pytest --cov=app --cov-report=html
🛑 Остановка всего стека
Остановить Docker Compose
cd social-api && docker compose down
Остановить + удалить данные (ОСТОРОЖНО!)
cd social-api && docker compose down -v

🔐 Система аутентификации
LOCKED · READ ONLY

Метод: JWT Bearer tokens. Access token (30 мин) + Refresh token (7 дней). Пароли хешируются через bcrypt (passlib).

Файлыapp/auth/jwt.py (токены), app/auth/dependencies.py (DI) АлгоритмHS256 (настраивается через JWT_ALGORITHM в .env) SECRET_KEY32+ символа, задаётся в .env (обязательно сменить!) МаршрутыPOST /auth/register, POST /auth/login, POST /auth/refresh Coreapp/core/token_manager.py — безопасное хранение OAuth токенов соцсетей Rate limiterapp/core/rate_limiter.py — защита от брутфорса
JWT python-jose passlib/bcrypt OAuth2PasswordBearer
